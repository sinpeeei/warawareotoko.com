ピンク色と一言にいいましても、いくつも種類がございます。

ピンク色とは？

ピンク（英語: pink）は赤と白を混ぜて出来る色の一つ。しばしば明るい赤と表現されるが、より正確には明度が高く彩度の低い赤である。ピンクは濃淡によってさまざまなバリエーションが存在する。 引用元:wikipedia
wikipediaに示されているPinkはこんな色でございます。おそらく一般的なピンク色かとおもいます。
